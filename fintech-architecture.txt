Product Architecture in detail:
Our product follows a microservices architecture, where the application is divided into multiple layers.
1. Frontend Layer
This layer contains the user interfaces:
Merchant UI
Payment UI
2. Backend Layer
The backend consists of three main areas: BFF, Application, and Data layers.
A. BFF (Backend for Frontend) Layer
Acts as an intermediary between the frontend and backend services.
Aggregates data from multiple microservices and presents it in a format suitable for the UI.
It can directly communicate with the Payment Microservice to retrieve transaction status quickly.
B. Application Layer
This layer contains the core business microservices:
Ledger Microservice – Maintains accounting and transaction information, such as payment amounts and order details.
Payment Microservice – Processes payments and communicates with external banking/payment systems.
Fraud Microservice – Uses ML to identify potentially fraudulent transactions.
Notification Microservice – Handles emails, messages, and other notifications.
C. Data Layer
This layer is part of the backend and is responsible for storing and managing application data used by the microservices.
