1. The core Terraform workflow:
The core Terraform workflow is inti, plan and destroy. First, when we run terraform init, to initialize the working directoy and download providers. Then terraform plan which desired state with current state and review infra changes. If plan looks correct, we run terraform apply to create or update the infrastrucure. when infra no longer needed, we run terraform destroy.
~/main.tf file - user define the provider, variables, and resources for desired state
~/terraform.tfstate file - current infra state created by terraform
